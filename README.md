# Super-Store-Order-Excel-project

Super Store Sales Analysis – Excel Dashboard

This project presents an interactive Super Store Sales Analysis Dashboard built in Microsoft Excel. The dataset contains order-level sales information, including order dates, shipping details, customer segments, geography, product categories, sales, quantity, discounts, profit, shipping costs, and order priority.

The data was analyzed and transformed using Excel formulas, PivotTables, PivotCharts, slicers, and dashboard techniques to create an interactive business reporting solution.

Key Objective

The objective of this project was to transform raw transactional sales data into an interactive management dashboard that makes it easier to monitor sales and profitability and identify patterns across products, customers, markets, countries, and time.
